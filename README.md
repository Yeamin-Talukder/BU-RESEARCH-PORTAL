# 🎓 BU Research Portal

A premium, web-based platform designed to streamline academic research submissions, peer review, and publication workflows for Barishal University.

---

## 📌 Project Overview

The **BU Research Portal** provides a structured, transparent, and role-based ecosystem where students and faculty can manage the entire lifecycle of an academic manuscript—from initial submission to final archival.

### Key Pillars
- **Immersive Design**: A premium, high-aesthetic interface focused on readability and user engagement.
- **Workflow Automation**: Automated statuses, notifications, and editorial assignment.
- **Role-Based Control**: Granular permissions for Authors, Reviewers, Editors, and Admins.
- **Centralized Archive**: A searchable repository of published research across all university departments.

---

## 📂 Repository Structure

This project is organized as a monorepo containing both the frontend and backend components.

| Component | Description | Tech Stack |
| :--- | :--- | :--- |
| [**Client**](./client/README.md) | The React-based frontend application. | Vite, React 19, TS, Tailwind, Framer Motion |
| [**Server**](./server/README.md) | The Node.js-based REST API. | Express, MongoDB, JWT, Nodemailer |

---

## 🚀 Quick Start

To get the entire project running locally, follow these steps:

### 1. Backend Setup
```bash
cd server
npm install
# Configure your .env (see server/README.md)
npm start
```

### 2. Frontend Setup
```bash
cd client
npm install
# Configure your .env (see client/README.md)
npm run dev
```

The portal will be accessible at `http://localhost:5173`.
